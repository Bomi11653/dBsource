# 🚀 dBsource 官网零基础部署指南（飞书版）

> **适用人群：** 没部署过网站、不熟悉 Linux 的同学  
> **预计耗时：** 首次约半天～1天（含等待证书、上传图片）  
> **最终效果：** `www.dbsourceaudio.com` 能打开，产品和图片正常显示

---

## 📌 先读这 3 句话

1. 你的网站 = **官网程序** + **内容后台（Strapi）** + **数据库** + **图片**，缺一不可。  
2. 代码在 GitHub，**产品和图片不在 GitHub**，要从你电脑传上去。  
3. 全程就是：**买服务器 → 装软件 → 上传代码 → 启动 → 绑域名**，按步骤做即可。

# 第 1 步：购买阿里云 ECS

## 1.1 打开购买页面

浏览器打开：https://ecs.console.aliyun.com/

点击 **创建实例**。

## 1.2 按下面选（照抄即可）

| 配置项 | 选什么 |
|--------|--------|
| 地域 | **华南（深圳）** 或你备案所在地区 |
| 实例规格 | **4核8G**（最低建议，不然构建可能卡死） |
| 镜像 | **Ubuntu 22.04 64位** |
| 系统盘 | 40GB 及以上 |
| 公网 IP | **分配公网 IPv4 地址** |
| 带宽 | 5Mbps 起 |

## 1.3 设置登录密码

- 记住 **root 密码**（写在记事纸上）
- 创建完成后，在实例列表找到 **公网 IP**

📝 **记下来：**

```
服务器 IP：___________________
root 密码：___________________
```

## 1.4 开放端口（安全组）

在 ECS 控制台 → 安全组 → 配置规则 → **入方向** 添加：

| 端口 | 授权对象 |
|------|----------|
| 22 | 你的办公网络（或先填 0.0.0.0/0 临时用） |
| 80 | 0.0.0.0/0 |
| 443 | 0.0.0.0/0 |

**【注意】** 不要开放 3003、1337 给全网，网站走 80/443 就行。

✅ **本步完成标志：** 能在控制台看到 ECS 状态为 **运行中**，有公网 IP。

# 第 2 步：用 SSH 连接服务器

## 2.1 Windows 用户（推荐 PowerShell）

打开 **PowerShell**，输入（把 IP 换成你的）：

```powershell
ssh root@你的服务器IP
```

第一次会问 `Are you sure...`，输入 `yes` 回车，再输入 root 密码。

**【提示】** 密码输入时屏幕不显示字符，正常的，输完直接回车。

## 2.2 连接成功的样子

你会看到类似：

```
root@iZxxxx:~#
```

后面有个 `#` 或 `$`，说明已经登录服务器了。

✅ **本步完成标志：** 能输入 Linux 命令，例如 `ls` 有反应。

# 第 3 步：安装必备软件

> 下面命令 **整段复制粘贴** 到 SSH 窗口，回车执行。  
> 出现 `Y/n` 问是否继续，输入 `Y` 回车。

## 3.1 更新系统

```bash
apt update && apt upgrade -y
```

## 3.2 安装基础工具

```bash
apt install -y curl git nginx ufw
```

## 3.3 安装 Node.js 20

```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt install -y nodejs
node -v
```

✅ 应显示 `v20.x.x`

## 3.4 安装 PM2

```bash
npm install -g pm2
pm2 -v
```

## 3.5 安装 PostgreSQL（数据库）

```bash
apt install -y postgresql postgresql-contrib
systemctl enable postgresql
systemctl start postgresql
```

创建数据库（把 `你的数据库密码` 换成强密码，记下来）：

```bash
sudo -u postgres psql <<'SQL'
CREATE USER strapi WITH PASSWORD '你的数据库密码';
CREATE DATABASE strapi OWNER strapi;
GRANT ALL PRIVILEGES ON DATABASE strapi TO strapi;
SQL
```

## 3.6 防火墙

```bash
ufw allow OpenSSH
ufw allow 'Nginx Full'
ufw enable
```

问是否继续，输入 `y`。

✅ **本步完成标志：** `node -v`、`pm2 -v`、`nginx -v` 都有版本号输出。

# 第 5 步：填写环境变量

## 5.1 官网环境变量

```bash
cp /var/www/dbsource/.env.production.local.example /var/www/dbsource/.env.production.local
nano /var/www/dbsource/.env.production.local
```

粘贴或修改为（**改成你的真实信息，勿提交到 Git**）：

```env
NEXT_PUBLIC_SITE_URL=https://www.dbsourceaudio.com
CMS_URL=https://cms.dbsourceaudio.com
NEXT_PUBLIC_CMS_URL=https://cms.dbsourceaudio.com
NEXT_PUBLIC_USE_MOCK_DATA=false

STRAPI_API_TOKEN=先留空_第10步再填
ADMIN_TOKEN=你设一个后台登录密码
```

保存方法：`Ctrl+O` 回车保存，`Ctrl+X` 退出。

📝 **ADMIN_TOKEN 就是你以后登录 `/admin/login` 的密码。**  
**【重要】** 改 `NEXT_PUBLIC_*` 后必须重新 `npm run build`。

## 5.2 Strapi 环境变量

```bash
nano /var/www/dbsource/cms/.env
```

粘贴并修改：

```env
HOST=0.0.0.0
PORT=1337

DATABASE_CLIENT=postgres
DATABASE_HOST=127.0.0.1
DATABASE_PORT=5432
DATABASE_NAME=strapi
DATABASE_USERNAME=strapi
DATABASE_PASSWORD=你的数据库密码

APP_KEYS=随机1,随机2,随机3,随机4
API_TOKEN_SALT=随机值
ADMIN_JWT_SECRET=随机值
TRANSFER_TOKEN_SALT=随机值
JWT_SECRET=随机值
```

**【提示】** “随机值” 在服务器执行下面命令，每次复制一个结果填进去：

```bash
openssl rand -base64 16
```

多执行几次，分别填到不同字段。

✅ **本步完成标志：** 两个 `.env` 文件都保存好了。

# 第 7 步：用 PM2 启动网站

## 7.1 创建 PM2 配置

```bash
nano /var/www/dbsource/ecosystem.config.js
```

粘贴：

```javascript
module.exports = {
  apps: [
    {
      name: "dbsource-web",
      cwd: "/var/www/dbsource",
      script: "node_modules/next/dist/bin/next",
      args: "start -p 3003 -H 127.0.0.1",
      env: { NODE_ENV: "production" },
      autorestart: true,
    },
    {
      name: "dbsource-strapi",
      cwd: "/var/www/dbsource/cms",
      script: "npm",
```

# 第 8 步：配置 Nginx（让外网能访问）

## 8.1 官网配置（含根域名跳转）

`dbsourceaudio.com` 自动跳到 `www`：

```bash
nano /etc/nginx/sites-available/dbsource-web
```

粘贴：

```nginx
# 根域名 → www
server {
    listen 80;
    server_name dbsourceaudio.com;
    return 301 http://www.dbsourceaudio.com$request_uri;
}

server {
    listen 80;
    server_name www.dbsourceaudio.com;

    client_max_body_size 50m;

    location / {
        proxy_pass http://127.0.0.1:3003;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

## 8.2 CMS 配置（含 WebSocket，Strapi 后台需要）

```bash
nano /etc/nginx/sites-available/dbsource-cms
```

粘贴：

```nginx
server {
    listen 80;
    server_name cms.dbsourceaudio.com;

    client_max_body_size 100m;

    location / {
        proxy_pass http://127.0.0.1:1337;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

## 8.3 启用并重载

```bash
ln -sf /etc/nginx/sites-available/dbsource-web /etc/nginx/sites-enabled/
ln -sf /etc/nginx/sites-available/dbsource-cms /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default
nginx -t
systemctl reload nginx
```

`nginx -t` 显示 `syntax is ok` = 成功。

✅ **本步完成标志：** Nginx 测试通过。

# 第 10 步：导入产品和图片 ⭐ 最重要

**【重要】** 不做这步，网站只有空壳或假数据！

## 10.1 在你 Windows 电脑上导出数据

打开 PowerShell：

```powershell
cd D:\dbsource\dbsource-audio-site\deploy\scripts
.\export-local-data.ps1
```

会生成文件，类似：

```
D:\dbsource\data\exports\dbsource-20250615-120000.tar.gz
```

## 10.2 上传到服务器

```powershell
scp D:\dbsource\data\exports\dbsource-*.tar.gz root@你的服务器IP:/root/
scp -r D:\dbsource\data\cms\uploads root@你的服务器IP:/root/uploads
```

⏱ uploads 约 2.8GB，上传时间较长，保持网络稳定。

## 10.3 在服务器导入

SSH 登录服务器后：

```bash
# 导入内容到数据库
cd /var/www/dbsource/cms
npx strapi import -f /root/dbsource-*.tar.gz --force

# 导入图片
cp -r /root/uploads/* /var/www/dbsource/cms/public/uploads/

# 重启
pm2 restart all
```

## 10.4 配置 API Token

1. 浏览器打开：`http://cms.dbsourceaudio.com/admin`  
2. 用本地 Strapi 相同邮箱登录  
3. 左侧 **Settings** → **API Tokens** → **Create new API Token**  
4. 类型选 **Full access**，复制生成的 Token  
5. 编辑环境变量：

```bash
nano /var/www/dbsource/.env.production.local
```

把 `STRAPI_API_TOKEN=` 后面贴上 Token，保存。

6. 重启官网：

```bash
pm2 restart dbsource-web
```

✅ **本步完成标志：**

- [ ] 产品页有约 112 个产品  
- [ ] 图片正常显示  
- [ ] `/admin/login` 能登录编辑

# 第 11 步：配置 HTTPS（小锁头）

## 11.1 申请免费证书

1. 打开阿里云 SSL 证书：https://yundun.console.aliyun.com/?p=cas  
2. 申请 **免费 DV 证书**  
3. 分别申请：`www.dbsourceaudio.com` 和 `cms.dbsourceaudio.com`  
4. 按提示做 DNS 验证  
5. 下载 **Nginx** 格式证书  

## 11.2 方式 A：Certbot 一键（更简单）

```bash
apt install -y certbot python3-certbot-nginx
certbot --nginx -d www.dbsourceaudio.com -d dbsourceaudio.com
certbot --nginx -d cms.dbsourceaudio.com
```

按提示输入邮箱、同意条款即可。

## 11.3 方式 B：阿里云证书手动配置

若不用 Certbot，下载 Nginx 格式证书后放到：

```
/etc/nginx/ssl/www/fullchain.pem
/etc/nginx/ssl/www/privkey.pem
/etc/nginx/ssl/cms/fullchain.pem
/etc/nginx/ssl/cms/privkey.pem
```

**官网 HTTPS**（写入 `dbsource-web`）：

```nginx
server {
    listen 80;
    server_name www.dbsourceaudio.com dbsourceaudio.com;
    return 301 https://www.dbsourceaudio.com$request_uri;
}

server {
    listen 443 ssl http2;
    server_name dbsourceaudio.com;
    ssl_certificate     /etc/nginx/ssl/www/fullchain.pem;
    ssl_certificate_key /etc/nginx/ssl/www/privkey.pem;
    return 301 https://www.dbsourceaudio.com$request_uri;
}

server {
    listen 443 ssl http2;
    server_name www.dbsourceaudio.com;
    ssl_certificate     /etc/nginx/ssl/www/fullchain.pem;
    ssl_certificate_key /etc/nginx/ssl/www/privkey.pem;
    client_max_body_size 50m;
    location / {
        proxy_pass http://127.0.0.1:3003;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

**CMS HTTPS**（写入 `dbsource-cms`）：

```nginx
server {
    listen 80;
    server_name cms.dbsourceaudio.com;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name cms.dbsourceaudio.com;
    ssl_certificate     /etc/nginx/ssl/cms/fullchain.pem;
    ssl_certificate_key /etc/nginx/ssl/cms/privkey.pem;
    client_max_body_size 100m;
    location / {
        proxy_pass http://127.0.0.1:1337;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

```bash

```

完整说明见：`deploy/docs/ECS-PM2-NGINX-DEPLOY.md` 第十节。

# ❓ 遇到问题怎么办？

## 问题 1：网站打开了但没有产品

| 检查 | 怎么做 |
|------|--------|
| 数据导入了没 | 重做第 10 步 |
| Token 填了没 | 检查 `STRAPI_API_TOKEN` |
| mock 关了吗 | `.env.production.local` 里要是 `NEXT_PUBLIC_USE_MOCK_DATA=false` |

改完后：`pm2 restart dbsource-web`

---

## 问题 2：图片裂开 / 不显示

- 第 10 步 uploads 没传完 → 重新 `scp` 上传  
- 传完后执行：`cp -r /root/uploads/* /var/www/dbsource/cms/public/uploads/`  
- `pm2 restart dbsource-strapi`

---

## 问题 3：页面显示 502 Bad Gateway

```bash
pm2 status          # 看是不是 online
pm2 logs dbsource-web --lines 50    # 看报错
```

不是 online → `pm2 restart all`

---

## 问题 4：构建失败 / 内存不够

服务器内存太小。临时加 swap：

```bash
fallocate -l 4G /swapfile
chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile
```

然后重新 `npm run build`。

---

## 问题 5：域名还跳到旧网站（Vercel）

- DNS 还没生效 → 等 30 分钟  
- 电脑缓存 → 手机 4G 试，或 `ipconfig /flushdns`  
- 阿里云解析里还有旧 CNAME → 删掉

---

## 问题 6：SSH 连不上

- IP 对不对  
- 安全组 22 端口开了没  
- 密码对不对（不显示是正常的）

---
